# go-panel docs — Master Index

Single entrypoint. Every tracked `.md` in this repo is listed here; if you add
one, add its row in the same PR.

go-panel is the reusable admin-panel framework behind go-grad, go-job and
oxpulse-admin. **The framework's whole reason to exist is that consumers do not
hand-roll admin UI.** If you read one file before changing anything that renders,
read [`DESIGN.md`](../DESIGN.md).

## Architecture decisions (`docs/adr/`)

Read ADR-003 before changing anything in the framework core.

| ADR | Decision |
|---|---|
| [ADR-001](adr/ADR-001-region-deploy-boundary.md) | Region is the deploy boundary — one deployment per region, residency follows the deploy |
| [ADR-002](adr/ADR-002-provider-uid-hashing.md) | Provider UIDs are stored as HMAC-SHA256, never in the clear |
| [ADR-003](adr/ADR-003-framework-core-and-i18n.md) | go-panel is the durable framework core; i18n lives in the resource framework; off-Directus |
| [ADR-004](adr/ADR-004-detailer-show-view.md) | The reusable Detail (Show) view primitive |
| [ADR-005](adr/ADR-005-role-gating.md) | Role-gated resources via the `RoleAuthenticator` capability |

## Conventions for this directory

- One decision per ADR, numbered, never renumbered. Superseding an ADR means a
  new file that says which one it supersedes, not an edit.
- A design doc describes what IS. If it describes what should be, it belongs in
  a plan, and plans do not live in a public repo.
- Add the row here in the same PR that adds the file. An index that lags is
  worse than no index: it is read as complete.
