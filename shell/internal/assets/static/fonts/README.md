Self-hosted fonts for the Iris skin (latin + cyrillic subsets, variable woff2).

- Inter Variable: @fontsource-variable/inter 5.3.0 (published 2026-07-19), SIL OFL 1.1
- Manrope Variable: @fontsource-variable/manrope 5.3.0 (published 2026-07-19), SIL OFL 1.1

Files are unmodified from the npm tarballs (`files/*-wght-normal.woff2`).
They are referenced only by the skin's @font-face; graphite pages never request them.
